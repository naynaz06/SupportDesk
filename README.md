# SupportDesk – Customer Support Management Dashboard

SupportDesk is a responsive customer support management dashboard built using HTML, CSS, and JavaScript. It helps administrators manage customer support tickets, monitor ticket statuses, and organize support requests through a simple and interactive interface.

##  Features

- **Dashboard Overview:** Displays total, open, pending, and resolved ticket statistics.
- **Ticket Management:** Create, view, edit, and delete support tickets.
- **Status Management:** Update ticket status between Open, Pending, and Resolved.
- **Search Functionality:** Search tickets by ticket ID, customer name, or subject.
- **Status Filtering:** Filter tickets based on their current status.
- **Ticket Details:** View detailed information about individual tickets.
- **Local Storage:** Automatically saves ticket data in the browser using LocalStorage.
- **Toast Notifications:** Displays success messages after important actions.
- **Responsive Design:** Mobile-friendly layout with a collapsible hamburger navigation menu.
- **Interactive UI:** Clean dashboard interface with modals, buttons, and dynamic statistics.

##  Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling, Flexbox, CSS Grid, and responsive design
- **JavaScript (ES6)** – DOM manipulation, event handling, and dynamic functionality
- **LocalStorage** – Client-side data persistence
